研究

Research

所属研究室：小谷・渡辺研究室（山梨大学 医工農学総合教育部 工学専攻 メカトロニクス工学コース）

サクランボ栽培における環境・果実データの統合によるデータ駆動型営農支援システムの構築

サクランボ栽培では、担い手不足や気候変動による品質の不安定化が課題となっています。本研究では、雨よけハウス内の天候・土壌データ、自動選果機による選果データ、営農記録をハウス単位で統合管理し、営農判断を支援するシステムを構築しています。IoT機器（Raspberry Pi とセンサ）で環境データを1時間ごとに取得し、LTE通信でクラウドへ送信して Web 画面で可視化します。農地の電源・通信制約に対応するため、間欠動作による省電力化にも取り組んでいます。

  • スマート農業
  • IoT・センシング
  • クラウド・Webシステム

プロジェクト

Projects

自律型ゴルフロボット（ロボコン）

カメラでボールを認識し、探索・接近・向き調整・打ち出しまでを自律で行うゴルフロボットを2人で製作しました。動作を工程ごとに分けて検証と改善を重ね、準優勝と特別賞を獲得しました。機体の一部の設計には 3D CAD（Fusion）と 3D プリンタを用いました。

サクランボ栽培営農支援システム

天候・土壌データの取得装置（Pi-field Mini／Raspberry Pi）、クラウド基盤（Google Cloud 上の Django／PostgreSQL）、データ閲覧用 Web インターフェースまでを設計・実装し、実際のサクランボ農地で運用しています。選果データに基づくハウス評価モデルも検討しました。
